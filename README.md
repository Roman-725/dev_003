# Digital Solutions Studio — сайт студии + демо-кейсы

Статический сайт на GitHub Pages. Без сборки: чистый HTML + CSS.

## Файлы

- `index.html` — основной сайт студии: услуги, работы, тарифы, контакты.
- `demo-remont.html` — демо-лендинг «ремонт квартир».
- `demo-beauty.html` — демо-лендинг «бьюти-студия».
- `demo-logistics.html` — демо-лендинг «грузоперевозки».
- `demo-style.css` — общие стили демо-страниц (палитра задаётся классом `body`).

## Что заменить перед продажей

1. **Форма заявок.** В `index.html` найдите `const FORM_ENDPOINT = 'YOUR_FORM_ID'`.
   Зарегистрируйтесь на [formspree.io](https://formspree.io), создайте форму, скопируйте ID
   (часть адреса после `/f/`) и подставьте вместо `YOUR_FORM_ID`. До этого форма честно пишет,
   что не подключена, и отправляет в ВК/Telegram.
2. **Телефоны в демо-сайтах.** Сейчас `+7 900 000-00-00` — заглушка, встречается в каждом демо-файле.
3. **Ссылки в демо.** `https://t.me/` в `demo-beauty.html` ведёт в пустоту — поставьте свой ник.
